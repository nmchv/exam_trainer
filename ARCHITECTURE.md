# Архитектура

## Поток приложения

`index.html` загружает нейтральную конфигурацию Supabase, стили и `src/app.js`. `appInitializer` загружает реестр и восстанавливает локальную попытку. `router.js` использует hash URL, поэтому прямые серверные маршруты не требуются на GitHub Pages.

При выборе экзамена `registryLoader` находит включённую запись. `taskLoader` загружает `exam.json` и все банки из `taskFiles`, проверяет версию, принадлежность к экзамену и уникальность ID, затем кэширует данные в рамках текущей вкладки.

### Начало / тренировка / экзамен

1. `testGenerator` фильтрует варианты по ID, номерам, тегам, сложности, использованным заданиям и списку ошибок; случайный выбор исключает повтор одного задания в попытке.
2. `examGenerator` подбирает позиции по конфигурации экзамена, учитывает группы и зависимости заданий; допускает фиксированный список ID.
3. `attemptService` собирает идентификатор попытки и карту её позиций. `storageManager` сохраняет весь незавершённый снимок локально; при доступной авторизованной сессии он также сохраняется в Supabase.
4. `taskEngine` передаёт демонстрационный ответ локальному `answerChecker`; реальные ответы проверяются Edge Function. Серверный банк не содержит правильных ответов.
5. `scoringEngine` рассчитывает локальные демонстрационные баллы по конфигурации. Для реальных заданий `finish-attempt` получает ключи на сервере, записывает результат и обновляет статистику.
6. `progressTracker` сохраняет историю, точный состав попытки, ответы, темы и список ошибок в браузере. `statisticsEngine` строит сводку из этих данных. Авторизованные пользователи могут получать облачную статистику через `get-statistics`.

## Модули

- `src/core/` — состояние, hash-router, шина событий и инициализация.
- `src/database/` — реестр, проверка конфигурации экзамена и загрузка JSON-банков.
- `src/engines/` — генерация, проверка, баллы, теория, прогресс и аналитика. Эти файлы не зависят от DOM.
- `src/components/` — DOM-компоненты и элементы задания/навигации.
- `src/pages/` — экраны каталога, тренировки, теории, варианта, результатов, кабинета и статистики.
- `src/services/` — локальное хранилище, Supabase Auth, попытки, пользовательские настройки и облачная статистика.
- `src/styles/` — токены темы, раскладка, компоненты и адаптивность.
- `public/database/` — общедоступный реестр и банки заданий. Не хранить здесь реальные ключи ответов.
- `supabase/` — миграция PostgreSQL/RLS и Edge Functions; доверенные переменные окружения остаются в Supabase.
- `schemas/` — JSON Schema версии 1.0.0.

## Контракты ключевых API

- `loadExamData(exam) -> { config, tasks, theory }`
- `generateTest(tasks, options) -> Task[]`
- `generateExam(tasks, specification) -> AttemptDefinition`
- `checkAnswer(task, answer) -> CheckResult` для локального демонстрационного банка
- `evaluateTask(task, answer, attemptId) -> Promise<CheckResult>` для UI
- `scoreAttempt([{task, result}], scoringRules) -> ScoreReport`
- `recordAttempt(attempt, scoreReport) -> Progress`
- `saveAttemptRemotely(attempt)` и `finishAttemptRemotely(attempt)` — сохранение/завершение авторизованных серверных попыток

## Темы

CSS-токены повторяют основную палитру nmchv.ru и используют Manrope. Внешний вид отделён от движков. Тёмная тема выставляется до загрузки модулей, светлая тема переключается пользователем; анимации учитывают `prefers-reduced-motion`. Иконки и иллюстрации исходного сайта не копируются.
